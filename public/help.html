📦 ออเดอร์ & CPA Tracker

ใช้ตอนไหน: ทุกครั้งที่มีลูกค้าสั่งซื้อจริง และทุกวันที่ยิงแอด

✅ ทำได้

  • บันทึกออเดอร์ (ชื่อ/แพ็กเกจ/ราคา/ที่อยู่/ช่องทางที่มา)
  • บันทึกค่าแอดรายวัน
  • คำนวณ CPA อัตโนมัติเทียบเพดาน 385 บาท
  • ดูยอดขาย/จำนวนออเดอร์เดือนนี้แบบเรียลไทม์

🚫 ทำไม่ได้

  • ไม่เชื่อมระบบรับเงินจริง — กรอกเองหลังลูกค้าโอนแล้วเท่านั้น
  • ไม่ดึงค่าแอดจาก Ads Manager อัตโนมัติ ต้องพิมพ์เอง
  • ไม่แจ้งเตือนเมื่อ CPA เกินเพดาน ต้องเข้ามาดูเอง
  • รองรับสกุลเงินบาทเท่านั้น

📨 กล่องข้อความ

ใช้ตอนไหน: ตอบแชทลูกค้าที่ทักเข้ามาทาง Facebook Messenger

✅ ทำได้

  • รับข้อความลูกค้าเข้ามาแบบเรียลไทม์ (เมื่อตั้งค่า Facebook เสร็จ)
  • แนะนำสคริปต์คำตอบที่ใกล้เคียงที่สุดให้อัตโนมัติ
  • เตือนชัดเจนถ้าคำถามต้องส่งต่อ Roger (ทะเบียน/สัตว์เลี้ยง ฯลฯ)

🚫 ทำไม่ได้ (สำคัญที่สุด)

  • ไม่ตอบลูกค้าอัตโนมัติเด็ดขาดในทุกกรณี — ต้องกด "ส่ง" เองเสมอ
  • ยังใช้จริงไม่ได้จนกว่าจะมีเพจ FB + Meta App + Page Access Token
  • รับได้แค่ข้อความตัวหนังสือ — รูป/สติกเกอร์ไม่ถูกบันทึก
  • ไม่มีระบบมอบหมายงานว่าใครตอบคนไหน

🗓 ปฏิทินคอนเทนต์

ใช้ตอนไหน: ติดตามว่าโพสต์ครบตามแผน 30 วันหรือยัง

✅ ทำได้

  • ติ๊กสถานะว่าโพสต์แต่ละวันแล้วหรือยัง
  • เช็กอัตโนมัติว่าครบ 12 โพสต์บังคับก่อนยิงแอดหรือยัง

🚫 ทำไม่ได้

  • ไม่โพสต์ขึ้นเพจ Facebook ให้ — ต้องไปโพสต์เอง
  • ไม่สร้างรูปให้ — ใช้ prompt จาก image-prompts.md ไปสร้างเองผ่าน Nano Banana/Canva
  • มีแค่คอนเทนต์ของ MAXIMUS เท่านั้นตอนนี้

💬 คลังสคริปต์แชท

ใช้ตอนไหน: ค้นหาคำตอบสำเร็จรูป

✅ ทำได้

  • ค้นหาด้วยคำสำคัญ เจอสคริปต์ทันที
  • กดคัดลอกไปวางที่อื่นได้เลย

🚫 ทำไม่ได้

  • ไม่ auto-fill เข้า Messenger โดยตรง ต้อง copy-paste เอง
  • เจอคำถามที่ไม่มีในคลัง ไม่แต่งคำตอบให้ — ต้องคิดเองหรือส่งต่อ Roger

🛡 เช็กคำต้องห้าม

ใช้ตอนไหน: ก่อนโพสต์ ad copy หรือคอนเทนต์ที่เคลมสรรพคุณ

✅ ทำได้

  • สแกนข้อความหาคำต้องห้ามแบบเรียลไทม์ขณะพิมพ์

🚫 ทำไม่ได้

  • ไม่ใช่การตรวจสอบทางกฎหมายที่สมบูรณ์ — เช็กแค่คำที่ตรงรูปแบบเท่านั้น
  • ไม่ทดแทนการตรวจจริงก่อนเผยแพร่ — เนื้อหาสำคัญให้ Roger ทวนอีกรอบเสมอ

🎨 ตกแต่ง Sale Page

ใช้ตอนไหน: ปรับหน้าตาเว็บขายตามเทศกาล/แคมเปญ

✅ ทำได้

  • เปลี่ยนสี 3 จุด, ฟอนต์, รูป header, ข้อความ hero
  • มีผลทันทีที่หน้าเว็บจริง ไม่ต้อง deploy ใหม่

🚫 ทำไม่ได้

  • แก้ได้แค่ส่วน Hero เท่านั้น — ตารางราคา/FAQ/นโยบาย แก้ผ่านนี้ไม่ได้
  • ไม่มีปุ่มย้อนกลับอัตโนมัติ — รีเซ็ตได้แต่กลับไปค่าเริ่มต้นในโค้ด ไม่ใช่ค่าก่อนหน้า

🛍 หน้าขายจริง (maximus-salepage.web.app)

นี่คือหน้าที่ลูกค้าเห็นจริง — ไม่ต้อง login ทุกคนเข้าได้

✅ ทำได้

  • แสดงสินค้า ราคา วิธีใช้ นโยบายคืนสินค้า
  • ปุ่ม CTA พาไปแชท Messenger สั่งซื้อ

🚫 ทำไม่ได้ (ตั้งใจ)

  • ไม่มี checkout/ใส่บัตรเครดิตในหน้านี้ — สั่งซื้อ/ชำระเงินที่แชทเท่านั้น
  • ไม่เก็บข้อมูลลูกค้า ไม่มีฟอร์มกรอกอะไร

🚫 สิ่งที่ทั้งระบบไม่ทำเลย โดยตั้งใจ

ไม่ใช่ข้อจำกัดทางเทคนิค แต่เป็นการตัดสินใจ

สิ่งที่ไม่ทำเหตุผล
ส่งข้อความหาลูกค้าอัตโนมัติป้องกันคำตอบผิด/เคลมเกินจริงหลุดไปโดยไม่มีคนเห็นก่อน
ประมวลผลการชำระเงิน/บัตรเครดิตให้มีจุดตรวจสอบจากคนเสมอก่อนยืนยันออเดอร์
ยิง/ปรับงบโฆษณาอัตโนมัติต้องอิงดุลยพินิจของทีม ไม่ใช่สูตรตายตัว
โพสต์คอนเทนต์ขึ้น Facebook อัตโนมัติต้องมีคนเห็นก่อนเผยแพร่เสมอ
ตั้งราคา/นโยบายเองเป็นการตัดสินใจธุรกิจ ระบบแค่ช่วยคำนวณ/แนะนำ
